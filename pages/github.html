Introduction à GitHub

GitHub est une plateforme pour la création de logiciels. Que vous démarrez un nouveau projet ou que vous contribuez à un projet existant, GitHub rassemble les outils et les flux de travail dont vous avez besoin à chaque étape du cycle de vie du développement logiciel (SDLC).
