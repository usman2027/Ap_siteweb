Introduction à la Ligne de commande Linux

La ligne de commande Linux est une interface textuelle permettant de contrôler directement le système d'exploitation en tapant des instructions au clavier. Contrairement à l'interface graphique (où l'on utilise une souris, des icônes et des fenêtres), la ligne de commande repose entièrement sur du texte.

Mémento : commandes Linux et leurs options

Commande Option / argument Description Exemple
Navigation et affichage
pwdAfficher le répertoire courant commande de base Affiche le chemin complet du répertoire dans lequel on se trouve pwd
-L Affiche le chemin logique, avec les liens symboliques (comportement par défaut) pwd -L
-P Affiche le chemin physique, sans les liens symboliques pwd -P
lsLister le contenu d'un répertoire commande de base Liste les fichiers et répertoires du dossier courant ls
-l Format détaillé : droits, propriétaire, taille, date de modification ls -l
-a Affiche aussi les fichiers cachés (ceux dont le nom commence par un point) ls -a
-h Affiche les tailles dans une unité lisible (Ko, Mo, Go), à utiliser avec -l ls -lh
-R Liste aussi le contenu des sous-répertoires (récursif) ls -R
-lah Combinaison très utilisée : détaillé, fichiers cachés et tailles lisibles ls -lah
cdChanger de répertoire commande de base Sans argument : retourne dans le répertoire personnel (home) cd
chemin Va dans le répertoire indiqué cd /var/log
.. Remonte au répertoire parent cd ..
~ Va dans le répertoire personnel de l'utilisateur cd ~
- Retourne au répertoire précédent cd -
clearEffacer le terminal commande de base Efface le contenu affiché dans le terminal (équivalent au raccourci Ctrl + L) clear
Gestion des fichiers et des répertoires
mkdirCréer un répertoire commande de base Crée un nouveau répertoire mkdir projet
-p Crée aussi les répertoires parents qui n'existent pas encore mkdir -p cours/linux/tp1
-v Affiche un message pour chaque répertoire créé mkdir -v projet
touchCréer un fichier vide commande de base Crée un fichier vide (ou met à jour sa date de modification s'il existe déjà) touch index.html
-c Ne crée pas le fichier s'il n'existe pas touch -c notes.txt
-d Fixe une date précise de modification touch -d "2026-10-08" notes.txt
cpCopier commande de base Copie un fichier cp a.txt b.txt
-r Copie un répertoire et tout son contenu (récursif) cp -r dossier/ copie/
-i Demande confirmation avant d'écraser un fichier existant cp -i a.txt b.txt
-v Affiche chaque fichier copié cp -v a.txt b.txt
-p Conserve les droits, le propriétaire et les dates d'origine cp -p a.txt b.txt
mvDéplacer ou renommer commande de base Déplace un fichier ou le renomme mv a.txt dossier/
-i Demande confirmation avant d'écraser un fichier existant mv -i a.txt b.txt
-n N'écrase jamais un fichier existant mv -n a.txt b.txt
-v Affiche chaque déplacement effectué mv -v a.txt dossier/
rmSupprimer commande de base Supprime un fichier (définitif : sans corbeille) rm a.txt
-i Demande confirmation avant chaque suppression rm -i a.txt
-f Force la suppression sans confirmation ni avertissement rm -f a.txt
-r Supprime un répertoire et tout son contenu (récursif) rm -r dossier/
-rf Suppression forcée et récursive (à utiliser avec précaution) rm -rf dossier/
catAfficher un fichier commande de base Affiche l'intégralité du contenu d'un fichier cat a.txt
-n Numérote toutes les lignes affichées cat -n a.txt
-b Numérote uniquement les lignes non vides cat -b a.txt
-s Regroupe les lignes vides consécutives en une seule cat -s a.txt
headAfficher le début commande de base Affiche les 10 premières lignes d'un fichier head log.txt
-n N Affiche les N premières lignes d'un fichier head -n 20 log.txt
-c N Affiche les N premiers octets d'un fichier head -c 100 log.txt
tailAfficher la fin commande de base Affiche les 10 dernières lignes d'un fichier tail log.txt
-n N Affiche les N dernières lignes d'un fichier tail -n 50 log.txt
-f Suit l'évolution du fichier en temps réel (pratique pour les logs) tail -f /var/log/syslog
-n +N Affiche le contenu à partir de la ligne N jusqu'à la fin tail -n +15 log.txt
nanoÉditeur de texte commande de base Ouvre un fichier dans un éditeur simple en ligne de commande nano page.html
-l Affiche les numéros de ligne dans l'éditeur nano -l page.html
+N Ouvre le fichier directement à la ligne N nano +12 page.html
Ctrl + O Raccourci dans nano : enregistre le fichier Ctrl + O puis Entrée
Ctrl + X Raccourci dans nano : quitte l'éditeur Ctrl + X
Recherche
grepChercher du texte commande de base Cherche un motif textuel dans un fichier et affiche les lignes grep "erreur" log.txt
-i Ignore la différence entre majuscules et minuscules grep -i "erreur" log.txt
-n Affiche le numéro des lignes correspondantes grep -n "erreur" log.txt
-r Recherche récursive dans tous les sous-dossiers grep -r "erreur" /var/log
-v Exclut le motif : affiche les lignes qui ne le contiennent pas grep -v "info" log.txt
findChercher des fichiers commande de base Recherche des fichiers et répertoires dans une arborescence find /home
-name Recherche par nom exact ou motif (sensible à la casse) find . -name "*.php"
-iname Recherche par nom sans tenir compte de la casse find . -iname "*.jpg"
-type f / d Filtre par type : f pour fichier, d pour dossier find . -type f
-size Filtre par taille (ex : +10M pour plus de 10 Mo) find . -size +10M
Droits et administration
chmodModifier les droits 755 Lecture/Écriture/Exécution pour le propriétaire, Read/Exec pour les autres chmod 755 script.sh
644 Lecture/Écriture pour le propriétaire, Read pour les autres chmod 644 page.html
+x Rend le fichier exécutable chmod +x script.sh
-R Applique les modifications de droits de façon récursive chmod -R 755 dossier/
chownChanger le propriétaire user Change le propriétaire d'un fichier ou dossier chown alice fichier.txt
user:group Change à la fois le propriétaire et le groupe attribué chown alice:www-data site/
-R Applique le changement à tout le contenu du dossier (récursif) chown -R alice:alice /var/www
sudoExécuter en administrateur commande de base Lance une commande avec les privilèges Superutilisateur (root) sudo apt update
-u user Exécute la commande sous l'identité d'un autre utilisateur sudo -u www-data ls
-i Ouvre une session terminal en tant que root avec son environnement sudo -i
-k Réinitialise l'autorisation : demande le mot de passe au prochain sudo sudo -k
Processus et ressources système
psLister les processus commande de base Affiche les processus actifs associés à la session courante ps
aux Affiche tous les processus du système avec des détails complets ps aux
-ef Affiche tous les processus au format standard Linux ps -ef
killArrêter un processus PID Envoie un signal d'arrêt propre au processus spécifié par son PID kill 1234
-9 PID Force l'arrêt immédiat du processus (signal SIGKILL) kill -9 1234
-15 PID Demande une fermeture normale (signal SIGTERM par défaut) kill -15 1234
dfEspace disque commande de base Affiche l'espace disque disponible sur les systèmes de fichiers df
-h Affiche les capacités dans un format lisible (Go, Mo) df -h
duTaille des dossiers commande de base Estime l'espace disque occupé par les fichiers et dossiers du
-sh Affiche un résumé global de la taille en unité lisible du -sh dossier/
-h --max-depth=1 Affiche la taille des sous-dossiers directs uniquement du -h --max-depth=1
Réseau et archivage
pingTester la connexion hôte Envoie des paquets ICMP pour vérifier l'inaccessibilité d'un hôte ping google.com
-c N S'arrête automatiquement après l'envoi de N paquets ping -c 4 8.8.8.8
-i N Définit un intervalle de N secondes entre chaque paquet envoyé ping -i 2 192.168.1.1
tarArchiver des fichiers -czvf Crée une archive compressée au format .tar.gz tar -czvf backup.tar.gz dossier/
-xzvf Extrait une archive .tar.gz dans le dossier courant tar -xzvf backup.tar.gz
-tzvf Lyste le contenu d'une archive sans l'extraire tar -tzvf backup.tar.gz
Aide
manAfficher la documentation commande de base Affiche la page de manuel officielle d'une commande man ls
-k mot Recherche un mot-clé dans les titres et résumés des manuels man -k copy
/mot Dans une page de manuel : lance la recherche d'un terme /mot puis Entrée
q Dans une page de manuel : quitte la lecture q
