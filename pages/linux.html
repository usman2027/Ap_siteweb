Introduction à Linux

Linux est un système d’exploitation, à l’instar de Windows ou macOS. Il permet d’exécuter des programmes, de gérer les fichiers, de communiquer avec les périphériques (clavier, écran, imprimante, etc.). Sans OS, impossible de faire fonctionner un ordinateur moderne. Vous pouvez également utiliser le langage SQL pour maintenir et optimiser les performances de la base de données.
